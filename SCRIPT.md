# Travel Café — "Every Cup Has a Passport"

A scroll-driven story for the Travel Café website. Each scene is a pinned "stage" that
plays like a short film as the visitor scrolls. Scroll position *is* the timeline: scroll
down to move forward, scroll up to rewind.

**Tone:** warm, curious, a little poetic. A travel journal written by someone who loves coffee.
**Palette:** espresso `#2b1a12`, crema `#f5ecdf`, latte `#c8a27a`, terracotta `#c65d3b`, sage `#7d8f69`.
**Type:** Fraunces (display, italic for narration) + Work Sans (UI and body).

Timings below are given as scene progress, from `0` (scene pinned) to `1` (scene released).

### Motion system notes (for developers)
- Every pinned scene is a `section.scene` containing a `position: sticky` `.stage`.
- Elements declare scroll-linked tweens inline with `data-tw`:
  `data-tw="0-.3: o 0 1, y 40 0; .8-1: o 1 0"`, which reads as "between 0 and 0.3 of the scene,
  fade opacity from 0 to 1 and move y from 40 to 0; between 0.8 and 1, fade out".
- Supported properties: `x`, `y`, `s` (scale), `sx`, `sy`, `r` (rotate), `o` (opacity),
  `d` (stroke draw, 0–1), `b` (blur), `fill`, `stop` (hex colours).
  An optional 4th token sets easing: `l` linear, `i` ease-in, `o` ease-out, `io` ease-in-out (default).
- `data-origin="646px 236px"` pins an SVG element's pivot in user units (the kettle tilts around its spout).
- Scenes that need more than tweens (the ship route, the horizontal menu, the timers) register a
  hook in `js/main.js`.
- `prefers-reduced-motion` turns off ambient loops (steam, flames, twinkle) and smoothing.
  The scroll-linked story still works because the visitor's own scrolling drives it.
